## 页面里有什么

- 每节先「说人话」，再给定义与定理（**证明默认折叠**，先自己推）
- 例题带步骤与可折叠答案；每节末尾有「易错点」与「自测」（点选判分，结果存在本地）
- 侧栏章节目录、`Ctrl/⌘ + K` 全文搜索、深浅色切换、打印样式、手机可用
- 高等代数带 3 个交互实验：行列式展开、特征值与特征向量、二次型正定
- MathJax 已内联，断网可读

1. **定理编号是程序按章自动生成的，不是教材原编号**。教材编号需对照纸质书，资料包里原本都标了「未核对」。
2. **目录按第五/六版结构整理**，个别节标题可能与手上印次略有出入（第 7、8、9 章最可能需要核对）。
3. 数学分析第 23 章（向量函数微分学）在部分印次为选学，若你的书没有，可整章略过。
